# Quick Reference — The AI Automation Templates -8

## The 14 Components, in Order
1. Opportunity Card — is this workflow worth mapping?
2. Workflow Map — trigger, inputs, rules, output
3. Task Brief — exactly what AI may and may not do
4. Source Packet — where inputs come from, how reliable
5. Output Contract — what "correct" means, checkably
6. Review Checklist — what a human checks before use
7. Exception Log — what didn't fit the rules
8. Decision Receipt — why you chose what you chose
9. Test Charter — the pilot's scope, before running it
10. Scale Gate — conditions required before expanding
11. Rollback Plan — written before you need it, not after
12. Operating Cadence — ongoing review rhythm
13. Training Record — who knows how to run it
14. Contribution Ledger — honest before/after, including costs

## Readiness Scoring (use before starting a pilot)
Score 1 (no) to 3 (yes, fully) on each:

| Question | Score |
|---|---|
| Is the trigger a single, identifiable event? | |
| Are the inputs consistent in format? | |
| Are the decision rules explainable in one paragraph? | |
| Is there a person who will own review? | |
| Does a manual fallback already exist? | |

**11-15:** Good pilot candidate. **7-10:** Map further before testing. **5-6:** Not ready — the workflow itself needs simplifying first.

## The Operator's Rule
> Do not automate a mess. Map the work, test one piece, and keep a person responsible for the result.
