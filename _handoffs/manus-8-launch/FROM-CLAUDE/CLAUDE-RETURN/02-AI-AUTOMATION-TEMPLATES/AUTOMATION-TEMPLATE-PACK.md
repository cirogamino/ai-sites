## 5. Output Contract
What "done correctly" looks like, in checkable terms — not a feeling.

- Format the output must match: ______________________
- Facts that must always be correct: ______________________
- Tone/style requirements: ______________________
- What makes an output unacceptable, automatically: ______________________

## 6. Review Checklist
The exact steps a human takes before any AI-assisted output is used.

- [ ] Output matches the format in the Output Contract
- [ ] Every fact/number checked against the source
- [ ] Tone matches brand/voice requirements
- [ ] No fabricated names, numbers, or claims
- [ ] Reviewer initials and date logged

## 10. Scale Gate
The conditions that must be true before expanding past the pilot.

- [ ] Pilot ran the full test-charter volume
- [ ] Error rate is known and acceptable (state the number: ____)
- [ ] Human review point is still in place
- [ ] No unresolved exceptions from the Exception Log
- [ ] Process owner explicitly approves scaling

## 11. Rollback Plan
Write this BEFORE you need it.

> If [specific failure condition] happens, we will [exact action] within [timeframe]. The person responsible for triggering rollback is [name]. The manual fallback process is [describe it — it must already exist].
