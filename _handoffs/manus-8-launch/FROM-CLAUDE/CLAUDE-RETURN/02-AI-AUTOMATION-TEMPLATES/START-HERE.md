2. Work through the 14 components in order. Some take five minutes, some take longer. Don't skip the Rollback Plan because it feels unnecessary — it's the one people regret skipping.
3. Use the tracker for the actual pilot, once you're ready to test.
4. This is a planning and testing framework. It does not build the automation for you, and it doesn't tell you which software to buy.
