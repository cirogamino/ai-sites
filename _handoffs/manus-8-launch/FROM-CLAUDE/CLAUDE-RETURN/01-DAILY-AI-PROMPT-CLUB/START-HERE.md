## How to use this

1. Do one day. Not three. One.
2. Use it on a real task you already had to do — not a made-up example.
3. Fill in the tracker row for that day before you move on. The value is in the record, not the prompt.
4. If a day doesn't apply to your work, adapt the prompt's structure to something that does. The four-part formula (Goal / Context / Constraints / Output) is what you're actually practicing.
