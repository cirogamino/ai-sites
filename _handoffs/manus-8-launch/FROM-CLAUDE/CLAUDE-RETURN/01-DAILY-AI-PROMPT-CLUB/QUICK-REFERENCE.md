# Quick Reference — The Daily AI Prompt Club -8

## The Four-Part Prompt

> **Goal:** Help me [the real result you need].
> **Context:** This is for [audience/situation]. Relevant background: [only what the AI needs].
> **Constraints:** Keep it [length, tone, limits]. Do not [what would make it unusable].
> **Output:** Return as [email, list, table, outline, script].

## The Five-Minute Loop

1. Choose one real task.
2. Fill in the four parts.
3. Run it once.
4. Change ONE variable.
5. Compare and keep the better instruction.

## Three Fast Repairs

- **Generic answer →** add one fact only an insider would know.
- **Too long →** set an exact limit and format ("5 bullets, under 18 words each").
- **Sounds unnatural →** describe voice with rules, not adjectives ("contractions, short sentences" not "friendly").

## The Operator's Rule
> One prompt you use, inspect, and improve is worth more than one hundred prompts you save.
